# TITAN CORE — Overdrive tester build

[Play TITAN CORE](https://chifeisoong.github.io/titan-core/)

A GPU-rendered warpunk tower-defense game. Five campaign sectors, seven turret families, five Titans, four elite operatives, eight bosses, ten battlefields and seeded Endless routes. No account or API key needed.

## Controls

- Choose a defense tab and card, or use keys 1–8. Click the battlefield to place it. Unavailable cards darken and display the requirement.
- Click a turret to upgrade or sell for 70% of invested salvage.
- Core III unlocks two Titan slots. Titan drops deal area damage; moving them does not repeat the drop.
- Core IV costs 700 salvage; Core V costs 1,050. Core V launches a free Ironclad every 30 combat seconds, up to three tanks, driving backward along alternating enemy routes and attacking ground enemies on that route.
- Select a unit, click Move, then its destination. Aircraft switch between Auto Hunt and Hold. Automatic Ironclads cannot be moved manually.
- Group Rangers within 130 range for stacking firepower, up to four teammates. Rook protects nearby allies; Dante deals bonus damage to bosses.
- Space launches/rushes, P pauses, Q selects Core Pulse. Pulse stores three charges, gaining one every 20 combat seconds. Mint, blue and violet bars show the reserve. Each strike spends one charge.
- Start Endless with 2,400 salvage and a free Sentry. Enter or roll a path seed, preview it, then choose an arena to lock the routes for the run. Restart preserves the seed; start a new run to reroll.

New threats: Scorch Hound, Prism Warden and Leech Drone; bosses Obsidian Bastion, Carrion Carrier and Chronarch. Open Threat Intel for counters.

Progress saves in your browser. Reports should include device/browser, route seed, sector or wave, actions and observed behavior.

## Hosting

This repository contains the compiled website. GitHub Pages serves main/root. Any static HTTP server also works; opening index.html as a file is unsupported.

Overdrive passed 47 model tests, 250 route seeds, production interaction checks and 15 responsive category/viewport combinations. The older v0.2.0-test download remains a versioned Maneuvers snapshot; the live link runs Overdrive.
