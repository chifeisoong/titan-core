# TITAN CORE — Tester build

A GPU-rendered warpunk tower-defense game. No account, API key or installation is needed to play the hosted build.

Five campaign sectors, seven turret families, five Titan heroes, ten environments, air combat and endless boss waves.

## Controls

- Select a defense tab, then a card or keys 1–7. Click the battlefield to place it.
- Click a turret to upgrade or sell. Upgrade the Core to III for two Titan slots.
- Select a unit, click Move, then its destination. Aircraft can switch between Auto Hunt and Hold.
- Group Rangers within 130 range for stacking damage and firing speed, up to four teammates.
- Space launches/rushes. P pauses. Q selects Core Pulse; its power and radius increase with Core tier.
- Start Endless skips the campaign with 2,400 salvage and a free Sentry.

Progress is stored in your browser. Reports should include browser/device, sector or endless wave, what you did and what happened.

## Hosting

This folder is the compiled website. Enable GitHub Pages from the main branch, root folder. It also works on any static HTTP server. Opening index.html as a file is unsupported.
