# TITAN CORE — Tester build

A GPU-rendered warpunk tower-defense game. No account, API key or installation is needed to play the hosted build.

Five campaign sectors, seven turret families, five Titans, five elite operatives, eight bosses, ten environments and seeded Endless routes.

## Controls

- Select a defense tab, then a card or keys 1–9. Click the battlefield to place it.
- Click a turret to upgrade or sell. Upgrade the Core to III for two Titan slots.
- Select a unit, click Move, then its destination. Aircraft can switch between Auto Hunt and Hold.
- Group Rangers within 130 range for stacking damage and firing speed, up to four teammates.
- Space launches/rushes. P pauses. Q selects Core Pulse; its power and radius increase with Core tier.
- Start Endless skips the campaign with 2,400 salvage. Roll or enter a path seed before choosing an arena.
- Core V launches a free reverse-route tank every 30 combat seconds, max three tanks.
- Pulse stores up to three shots. Titan drops cause area damage.
- Unavailable cards darken; their requirement or cooldown remains visible.
- Core IV unlocks three research upgrades per regular unit; replacements inherit them.
- Nyx Volta stuns groups. Endless mixes four open layouts and two broad-loop layouts, with three spacious build areas and room for 36 towers.
- Save Battle Snapshot after a run exports your battlefield and score as a PNG.

Progress is stored in your browser. Reports should include browser/device, sector or endless wave, what you did and what happened.

## Hosting

This folder is the compiled website. Enable GitHub Pages from the main branch, root folder. It also works on any static HTTP server. Opening index.html as a file is unsupported.
